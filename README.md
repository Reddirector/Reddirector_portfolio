# RED DIRECTOR Portfolio

A React and Vite portfolio for selected systems, model interpretability, and software projects.

## Run locally

```sh
npm install
npm run dev
```

## Method section

The Method section presents case notes for the SAE Reproduction, Orchestration Engine, and Pentagon projects. It advances automatically after a 15-second hold while the section is visible. Use **Pause auto** to stop rotation and **Resume auto** to restart it; the case buttons also let visitors choose a project manually. Reduced-motion preferences disable the slide animation.

## Source structure

- `src/PortfolioApp.jsx` — page sections and interactions
- `src/content.js` — portfolio copy and project details
- `src/index.css` — visual styles and responsive behavior
